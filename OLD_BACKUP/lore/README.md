## Overview

This folder contains the complete lore documentation for Textical. The lore is designed to provide an immersive, consistent backstory for all game systems, locations, characters, and events.

---

## Lore Documents

### 1. World Foundation
**File:** [`01_world_foundation.md`](01_world_foundation.md)

The foundational lore establishing:
- The cosmology of Aethoria (the Pillars of Creation)
- The Five Pillars: Kragor, Sylvara, Noxara, Igneth, Marinor
- Historical timeline (Age of Primordials through Current Era)
- The Great Cataclysms (First and Second)
- World geography and metaphysics

### 3. Locations

## Lore Consistency Notes

### Key Lore Elements Addressed

1. **Great Gem War** ✅
   - Now has full historical context
   - Factions, battles, aftermath established

2. **Solar Vanguard** ✅
   - Complete history from founding to fall
   - Connected to Elm Forest location
   - Related to Order of the Dawn

3. **Age of Kings** ✅
   - Kingdom of Aethor established
   - The Sundering explained
   - Forbidden Grove as epicenter

4. **Legendary Materials** ✅
   - Dragon Scale: Dragons in Volcanic Reaches
   - Phoenix Hide: Phoenix spawn locations
   - Kraken Leather: Deep sea zones
   - World-Tree Essence: Quest-only content

---

## Usage Guidelines

### For Developers

- All new game content should reference this lore
- Location descriptions should match location lore
- Item names should be consistent with artifact lore
- Character backgrounds should align with faction lore

### For Writers

- Maintain consistency with established canon
- Use the timeline for historical references
- Reference existing factions before creating new ones
- Connect new content to existing lore where possible
